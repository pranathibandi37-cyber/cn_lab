# CN Lab Exam – Computer Networks Lab (24BCE2079)

Packet Tracer files (built and tested in Cisco Packet Tracer 9.0) and C programs for the lab experiments.

## Packet Tracer (Q8–Q15)
| Q | Experiment | File |
|---|---|---|
| Q8 | IP addressing and default gateway | `Q8_IP_Gateway.pkt` |
| Q9 | RIP / OSPF | `Q9_RIP.pkt`, `Q9_OSPF.pkt` |
| Q10 | SMTP and DNS | `Q10_SMTP_DNS.pkt` |
| Q11 | Unicast routing – LSR (OSPF) | `Q11_LSR_OSPF.pkt` |
| Q12 | Unicast routing – DVR (RIP) | `Q12_DVR_RIP.pkt` |
| Q13 | Unicast routing – BGP | `Q13_BGP.pkt` |
| Q14 | TCP and UDP traffic control | `Q14_TCP_UDP.pkt` + `Q14_code.py` |
| Q15 | DNS client–server | `Q15_DNS_Client_Server.pkt` |

To open: click the file → **Download raw file** → open in Packet Tracer.
For Q14, click **Run** on PC0 first, then on PC1.
